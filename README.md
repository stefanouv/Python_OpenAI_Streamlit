# Python, OpenAI API & Streamlit Projects

A collection of three educational projects developed while learning the fundamentals of Python application development, Streamlit, and OpenAI API integration.

The projects explore interactive dashboards, AI-generated information, data visualization, and interactive quizzes.

## Projects

### 1. Financial Comparative Analysis Dashboard

An interactive dashboard for comparing two stocks using historical market data, financial metrics, charts, volatility analysis, and AI-generated financial reports.

**Technologies:** Python, Streamlit, OpenAI API, yfinance, Pandas, NumPy, Plotly.

[View project folder](./Financial-Dashboard/)

### 2. AI Health Risk Analyzer

An interactive application that generates structured AI-based information about diseases, including symptoms, risk levels, statistics, prevention tips, recovery options, and medication information.

**Technologies:** Python, Streamlit, OpenAI API, Pandas, JSON.

[View project folder](./AI-Health-Risk-Analyzer/)

**Important:** AI-generated medical information and statistics have not been independently verified. This application is for educational purposes only and is not a medical diagnostic tool.

### 3. AI Quiz Generator

An interactive multiple-choice quiz application featuring score tracking, progress indicators, answer explanations, and AI-generated questions based on user-provided topics.

**Technologies:** Python, Streamlit, OpenAI API, JSON, Object-Oriented Programming.

[View project folder](./AI-Quiz-Generator/)

## Learning Objectives

These projects demonstrate practical experience with:

- Building interactive web applications using Streamlit.
- Integrating external APIs into Python applications.
- Processing structured data using JSON and Pandas.
- Visualizing data and presenting analytical results.
- Using Streamlit session state to manage interactive application state.
- Organizing Python projects and managing dependencies.

## Requirements

- Python
- Required packages listed in each project's `requirements.txt`
- An OpenAI API key with access to the configured model for AI-powered features

**API note:** The AI-powered features have not been tested with an active OpenAI API account. API usage may incur additional costs. The applications currently require an API key at startup.

## Purpose

This repository represents practical learning exercises completed while exploring Python, Streamlit, and the OpenAI API. The projects are intended for educational purposes and may be extended with additional features and improvements.

## Disclaimer

AI-generated outputs may contain inaccurate or incomplete information. The financial and health-related projects are educational demonstrations and should not be used as the sole basis for financial or medical decisions.
